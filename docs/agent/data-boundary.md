# 数据与隐私边界：strata-agent

> 路径：`docs/agent/data-boundary.md`
> 依据：《Agent 开发标准》§3 D9（本地副本：`/Users/caspian/ai开发规范/agent-development-standard.md`）
> 回答一个问题：**哪些数据会离开我们的边界，去往哪里，留多久。**
> 现状：本地单机部署、样例数据、无外部用户。存储选型已定（ADR-0004），表结构与保留期未定。
> ［本团队］分级名称与保留期为团队约定；PII 与记忆隔离要求参考 OWASP LLM02 / LLM08 / ASI06。

## 1. 数据分级

| 级别 | 定义 | 能否进上下文 | 能否进日志 | 能否进第三方模型 |
| --- | --- | --- | --- | --- |
| 公开 | 仓库文档、已发布的示例说明 | 是 | 是 | 是 |
| 内部 | 任务记录、指标、评测样本、知识片段 | 是 | 是（摘要） | 按 provider 条款 |
| 机密 | 模型 API Key、连接串、未公开的评测基线 | 否 | 否 | 否 |
| 个人数据 | 可识别到自然人的内容（合同当事人信息、会话偏好） | 必要时，且需脱敏 | 否 | 待补：缺 provider 条款核对 |

## 2. 数据流

| 数据 | 分级 | 来源 | 去向 | 存储位置 | 保留期 |
| --- | --- | --- | --- | --- | --- |
| 任务输入（HTTP / 命令行） | 内部，可能含个人数据 | 调用方 | 模型上下文、trace | PostgreSQL（任务表，待建） | 待补 |
| 会话消息 | 内部/个人 | 调用方 | 模型上下文 | PostgreSQL（权威状态，推断自 ADR-0004「权威状态落 PostgreSQL」；表结构待补） | 待补 |
| 跨会话记忆条目 | 个人 | 会话写入 | 后续会话上下文 | Redis（非权威源，ADR-0004） | 待补 |
| 知识片段与向量 | 内部 | 样例知识库导入 | 检索结果 → 上下文 | PostgreSQL + pgvector | 待补 |
| 模型请求与响应 | 含上下文明文 | 平台 | **离开边界 → 火山方舟 OpenAI 兼容端点** | 仅 trace 摘要 | 待补 |
| 工具入参与返回 | 内部 | 工具 / MCP server | Agent 上下文 | PostgreSQL（调用记录表，待建） | 待补 |
| trace 与结构化日志 | 内部，需脱敏 | 平台 | 观测后端（待选） | 待补 | 待补 |
| 评测样本 | 内部 | `evals/*.jsonl` | 评测运行器 | 仓库 `evals/`（未建） | 随仓库永久 |
| 模型 API Key | 机密 | 环境变量 / `.env` | 模型 provider | 仅本机环境变量；`.env` 已 gitignore | 不落盘到仓库 |

**离开边界的只有两处**：① 模型服务（火山方舟）；② 未来接入的 MCP server。除此之外全部留在本机 Compose 栈内。

**规则**：每一行都要能回答"它去了哪里"。答不上来的数据，默认不允许进入上下文。
